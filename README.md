# 🛒 Retail Store SQL Project

## 📌 Project Overview

This project focuses on analyzing a retail store database using SQL and MySQL.

The database contains information about:

- Customers
- Products
- Orders
- Order Items
- Payments
- Product Reviews

The goal of this project is to use SQL queries to answer different business questions related to sales, customers, products, inventory, and payments.

## 🛠️ Tools Used

- MySQL
- SQL
- MySQL Workbench

## 📊 SQL Concepts Used

- SELECT
- WHERE
- DISTINCT
- ORDER BY
- GROUP BY
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- UNION

## 💼 Business Questions

Some of the questions analyzed in this project include:

- What is the total revenue?
- What is the average order value?
- How many orders were placed?
- Which customers placed orders?
- Which customers have not placed orders?
- Which products were sold?
- Which products are out of stock?
- Which category has the most products sold?
- How much payment was received through each payment method?
